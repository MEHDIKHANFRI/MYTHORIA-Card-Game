 MYTHORIA — Chroniques du Voile

Présentation du projet

Projet de site web interactif de cartes à collectionner dans un univers dark fantasy. Le joueur pourra acheter des boosters avec une commande simulée, ouvrir ses cartes, consulter son grimoire et composer un deck.

 Pages prévues

| Page | Fonction principale |
| --- | --- |
| Home | Présentation du jeu, catégories, boosters et cartes légendaires |
| Boutique | Quatre boosters, quantités, panier persistant et commande simulée |
| Ouverture | Tirage aléatoire pondéré, animation et ajout des cartes à la collection |
| Grimoire | Livre illustré, pages navigables, filtres et détails des cartes |
| Deck | Ajout/retrait des cartes possédées, plafond de vingt cartes, statistiques et sauvegarde |

 Technologies

HTML5 · Tailwind CSS (obligatoire) · JavaScript · LocalStorage · Git · Vercel

 Règles retenues

- La commande est simulée ; aucun paiement réel n’est effectué.
- La collection peut contenir plusieurs exemplaires d’une carte.
- Le deck contient au maximum vingt cartes et une seule copie par identifiant du catalogue.
- Les prix, compositions et probabilités retenus seront documentés.
